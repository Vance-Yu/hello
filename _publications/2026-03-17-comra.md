CoMRA is a framework for automated code migration that combines retrieval-augmented generation (RAG) with multi-agent collaboration. It achieves 98% conversion accuracy on a Qt4-to-Qt5 migration benchmark of 194 independently compilable programs, and its workflow generalizes to cross-ecosystem language-version and build/dependency migrations (e.g., Python and Java).
