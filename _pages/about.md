I am **Vance Yu (郁万祥)**, a master's student in computer science at [Nankai University](https://www.nankai.edu.cn/), advised by Prof. [Yuzhi Zhang](https://cs.nankai.edu.cn/info/1085/1126.htm). I will start my Ph.D. at the [University of Hong Kong](https://www.hku.hk/) in 2027.

My research lies at the intersection of software engineering and large language models, with a focus on automated code migration and program transformation, retrieval-augmented generation (RAG), and multi-agent collaboration for code-related tasks.

## Research interests

- Automated code migration & program transformation
- Retrieval-augmented generation (RAG)
- Multi-agent LLM systems
- LLM for software engineering / code intelligence
